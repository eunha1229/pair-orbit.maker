# PAIR ORBIT MAKER v16.3.6

Rich-text typography fix:
- Enter now inserts BR instead of browser-generated DIV/P blocks.
- Rich-text descendants inherit font family, line-height and letter spacing.
- S/M/L/XL size spans explicitly inherit line-height, so shrinking text restores normal spacing.
- Bold/Italic/Strike no longer use execCommand; controlled spans are used instead.
- Bold therefore keeps the selected font family and current font size.
- Legacy direct DIV/P blocks are normalized while editing.
- v16.3.5 layout / PNG fixes retained.
