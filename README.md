# PAIR ORBIT MAKER

캐릭터 페어 소개 페이지를 만들고 PNG 이미지와 JSON 데이터로 저장할 수 있는 웹 에디터입니다.

**Version:** v16.5.30  
**Credit:** made by @2by4_JourNey

## 사용 방법

1. GitHub 저장소의 **Settings → Pages**로 이동합니다.
2. **Build and deployment → Source**에서 **Deploy from a branch**를 선택합니다.
3. Branch를 **main**, 폴더를 **/(root)**로 지정하고 저장합니다.
4. 배포가 완료되면 표시되는 GitHub Pages 주소로 접속합니다.

로컬에서도 `index.html` 파일을 브라우저로 열어 사용할 수 있습니다.

## 주요 기능

- 캐릭터 프로필과 이미지 배치 편집
- 캐릭터별 컬러 팔레트(이름 및 HEX 색상 코드)
- 텍스트, 타임라인, 장면, 스티커 편집
- PNG 내보내기 및 JSON 데이터 저장·불러오기

## 참고

- 브라우저에서 실행되는 정적 HTML 페이지로, 서버 구축이 필요하지 않습니다.
- 일부 폰트 및 PNG 저장용 라이브러리를 외부 CDN에서 불러오므로 인터넷 연결이 필요할 수 있습니다.
- 편집 데이터 보존을 위해 JSON 파일을 별도로 저장해 두세요.
