# PAIR ORBIT MAKER

1~6인 캐릭터/페어 자료를 한 페이지에 정리하고 PNG로 저장할 수 있는 웹 메이커입니다.

## 주요 기능

- 1~6인 템플릿
- COMPACT / WIDE 캐릭터 레이아웃
- 페어 대표 이미지 비율·위치·스케일 조정
- 캐릭터별 전신 신장 비례 및 발끝 정렬
- 두상 비율·위치·스케일 조정
- 캐릭터별 색상, 폰트, 카드/페이퍼 스타일 설정
- 키워드 자유 추가
- 필수 요소 / NG 요소
- 타임라인 및 장면 추가·삭제
- 장면 이미지 3:1 기본 비율 및 구도 조정
- 자유 스티커 이동·크기·회전·반전·레이어 조정
- Paper 패턴 / Border / Edge Accent / Corner Ornament / Orbit 장식
- PNG 저장
- 편집 상태를 포함한 HTML 저장

## GitHub Pages 배포

이 폴더의 파일을 저장소 루트에 업로드한 뒤 GitHub 저장소의
`Settings → Pages`에서 배포 소스를 설정하면 됩니다.

별도의 빌드 과정은 필요하지 않습니다. `index.html`을 바로 실행하는 정적 웹페이지입니다.

## 사용 시 참고

- 웹폰트와 PNG 렌더링 라이브러리를 외부 CDN에서 불러오므로 인터넷 연결이 필요합니다.
- 전신 신장 비교는 투명 PNG 사용을 권장합니다.
- 장면 이미지 기본 권장 비율은 3:1 (예: 1500 × 500 px)입니다.
- PNG 저장 시 브라우저와 이미지 크기에 따라 잠시 시간이 걸릴 수 있습니다.
