# PAIR ORBIT MAKER

1~6인 캐릭터/페어 자료를 한 페이지에 정리하고 PNG로 저장할 수 있는 정적 웹 메이커입니다.

## 주요 기능
- 1~6인 / COMPACT·WIDE 레이아웃
- 페어·두상·장면 이미지 비율/스케일/위치 조정
- 전신 투명 여백 감지, 발끝 정렬 및 신장 비례
- 캐릭터별 색상, 폰트, Card/Paper 및 Decoration 설정
- 타임라인 / 이미지·텍스트 장면 추가·삭제
- 자유 스티커 이동·크기·회전·반전·레이어
- 서술형 본문 부분 선택 후 Bold / Italic / Strikethrough / Highlight
- PNG 및 편집 가능한 HTML 저장

## 본문 서식
서술형 본문에서 원하는 문구를 드래그하면 작은 툴바가 나타납니다.
`B` 굵게, `I` 기울임, `S` 취소선, `H` 포인트색 강조를 적용할 수 있습니다.
서식은 PNG와 편집 가능한 HTML 저장본에도 유지됩니다.

## GitHub Pages
저장소 루트에 `index.html`과 `README.md`를 업로드하고
Settings → Pages에서 배포 소스를 설정하면 됩니다. 별도 빌드는 필요하지 않습니다.

장면 이미지 기본 권장 비율: 3:1 (1500 × 500 px)
