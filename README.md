# PAIR ORBIT MAKER v16

1~6인 캐릭터/페어 자료 제작용 정적 웹 메이커입니다.

## 저장
- SAVE AS PNG: 완성 이미지를 PNG로 저장
- SAVE DATA (.JSON): 현재 편집 데이터 전체 저장
- LOAD DATA (.JSON): 저장한 데이터를 최신 사이트에서 다시 불러오기
- JSON에는 schemaVersion과 appVersion이 포함됩니다.

JSON에는 텍스트와 리치 텍스트 서식, 이미지(Data URL), 이미지 위치/스케일,
캐릭터 설정, 타임라인, 장면, 스티커, 색상, 폰트, Typography, Paper Decoration 등이 포함됩니다.

## v16 수정
- editable HTML 저장을 JSON 데이터 저장/불러오기로 교체
- Orbit opacity/size 조절 수정
